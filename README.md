# HARTCATCH宵ちゃん！

Phaser 3 製の「動くキャラをハートでつかまえる」ゲームです。内部解像度は 540 × 960（9:16）。
基本の作り（画面構成・シーン構成・CSS での配置）は game1 と同じです。

## 遊び方

- 制限時間 **30秒**。何回つかまえられるかを競います。
- 画面を押すと、その位置に **ハート** が出て、指（マウス）についてきます。
- **指を離した瞬間** に、キャラがハートの中にいれば **キャッチ（+1）**。いなければ「おしい！」でミス。
- ハートは押してから **3秒** で消えます（時間切れでミス）。3秒以内に離せば、その時点で消えます。
- ハートは同時に1つだけ。時間切れになったら、いったん指を離してから押し直します。
- **10秒ごと** にキャラが速くなります（3段階。後半はときどきダッシュします）。
- つかまえるキャラは宵ちゃん1人です（タイトル画面では、ハートから逃げ回る演出が流れます。ジグザグ・ひとやすみ・おいかけっこ・ぴょんぴょん・だるまさんがころんだ の5パターンが、1周ごとに向きを変えながら順番に出ます）。
- ハイスコア（つかまえた回数）はブラウザの localStorage に保存され、タイトル画面に表示されます。

## 起動方法（XAMPP）

Apache を起動して次の URL を開きます。

```bash
start http://localhost/game2/
```

ビルドは不要です。`index.html` を直接開く（`file://`）と画像が読み込めないので、必ず Web サーバー経由で開いてください。
Phaser 3 は CDN（jsdelivr）から読み込むため、ネット接続が必要です。

```
game2/

│   ├── main.js             Phaser の起動設定
│   └── scenes/
│       ├── BootScene.js    画像読み込み＋雲/粒子/ハートのテクスチャ生成

    ├── chara_1.png         宵ちゃん（200 x 200）
```

ハートの画像はファイルではなく、`BootScene` でコードから描いています。

## つかまえる判定

- ハートの形は `UI.heartPoints()` のハート曲線で、**見た目のハートと判定範囲は同じ形** です。
- キャラ側は `GAME.CHARA` の `core`（元画像のピクセル基準の四角）の **中心の1点** で判定します。
  この点がハートの中に入っていれば「つかまえた」です。
- 判定を目で確認したいときは `js/config.js` の `GAME.DEBUG` を `true` にすると、
  ハートの判定範囲（マゼンタ）とキャラの判定点（赤い点）が表示されます。

## 調整したいとき

数値はすべて `js/config.js` にまとまっています。

| 項目 | 設定 |
| --- | --- |
| 制限時間 | `GAME.DURATION` |
| タイトルロゴの大きさ・位置・切り出し範囲 | `GAME.LOGO_HEIGHT` / `GAME.LOGO_Y` / `GAME.LOGO_TRIM` |
| ハートの大きさ（＝つかまえられる範囲） | `GAME.HEART.SIZE` |
| ハートが消えるまでの時間 | `GAME.HEART.LIFE`（ms） |
| 点滅し始める残り時間 | `GAME.HEART.WARN`（ms） |
| ハートを指から上にずらす | `GAME.HEART.OFFSET_Y`（マイナスで上。スマホで指に隠れて見づらいとき） |
| キャラの画像・表示サイズ・判定点 | `GAME.CHARA` の `file` / `width`（タイトル画面は `titleWidth`）/ `core` |
| キャラの大きさの変動（0.9〜1.1倍） | `GAME.CHARA_SCALE` |
| キャラの動ける範囲 | `GAME.FIELD` |
| つかまえた後、次が出るまで | `GAME.RESPAWN_DELAY`（ms） |
| 難易度が上がる間隔 | `GAME.PHASE_SECONDS` |
| 各段階の速さ・向きを変える間隔・ダッシュ率 | `GAME.PHASES` |
| ダッシュの速さ・長さ | `GAME.DASH_SCALE` / `GAME.DASH_TIME` |
| 称号 | `GAME.RANKS`（`maxMiss` を付けると「ミスがこの回数以下のときだけ」の称号になる） |
| タイトルの追いかけっこのパターン（速さ・緩急・動き方） | `TitleScene.js` 先頭の `CHASE_PATTERNS` |

| 段階 | 速さ(px/秒) | 向きを変える間隔 | ダッシュ率 |
| --- | --- | --- | --- |
| 0–10秒 | 190–250 | 0.7–1.5秒 | 0% |
| 10–20秒 | 240–320 | 0.55–1.2秒 | 15% |
| 20–30秒 | 300–400 | 0.4–0.95秒 | 30% |

**簡単すぎる / 難しすぎるとき** は、`GAME.HEART.SIZE`（ハートの大きさ）と `GAME.PHASES` の速さで調整するのが手軽です。

## 補足

- localStorage のキーは `lovecatch.best`（ハイスコア）です。
  game1 と同じ `localhost` で動かしても記録は混ざりません。
- 長押しで遊ぶため、右クリックメニュー（`main.js` の `disableContextMenu`）と、
  スマホの長押しメニュー・文字選択（`style.css`）を出さないようにしています。
